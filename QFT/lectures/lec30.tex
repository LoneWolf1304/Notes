\section*{Lecture 30: Wick's Theorem}
\addcontentsline{toc}{section}{Lecture 30: Wick's Theorem}
In the previous section we looked into an introduction to interacting fields and found general expressions for the correlation functions
$$\vacb \ST \{\phi(x_1)\phi(x_2)\ldots \phi(x_n)\}\vac$$
  where we need to find the time-ordered product of free fields. These are efficiently given by a method of computation. As a gross approximation, Wick's theorem tells us how to go from time ordered products to normal ordered products.\\[0.2cm]
Recall from sec \ref{sec:normalorder} that normal ordered products meant that all the creation operators are sent to the left. This is particularly useful, since if creation operators are on the left (and annihilation are on the right), then these will kill the vacuum from both sides when expectation is taken, which might simplify our calculations somewhat.  \\[0.2cm]
We will use the notation $\phi(x_i) \equiv \phi_i$ and for the Feynman propagator, $D\tund{F}(x_i - x_j) \equiv \triangle_{ij}$
\subsection{Few calculations}
For $n=1$, $\ST\{\pho\} = \pho$ since there is only one field. For $n=2$, $$\ST\{\pho, \phii\} = \Theta(x_1^0 - x_2^0) \pho +\Theta(x_2^0 - x_1^0)\phii$$ which we already know, however, let us see this a bit differently. For that, decompose the Heisenberg field $\phi(x)$ into $\phi^+(x) + \phi^-(x)$ where   
\begin{align*}
    \phi^+(x) &:= \int \meas{\vb{p}} \frac{1}{\sqrt{2E_{\vb{p}}}}\annp e^{-i p\cdot x} \\
 \phi^-(x) &:= \int \meas{\vb{p}} \frac{1}{\sqrt{2E_{\vb{p}}}}\crep e^{i p\cdot x} 
\end{align*}
Note the unfortunate notation that $+$ comes with annihilation and $-$ comes with creation operators. Normal ordering is there if minuses (if any) are to the left. Now suppose that we assume the time-order $x_1^0>x_2^0$ which gives 
\begin{align*}
    \ST\{\phi_1, \phi_2\} = \phi_1 \phi_2 &= (\php{1}+ \phm{1})(\php{2}+ \phm{2})\\
    &=\php{1}\php{2}+ \mathcolor{blue}{\php{1}\phm{2}}+ \phm{1}\php{2}+\phm{1}\phm{2}\\
    &=\php{1}\php{2}+\phm{2}{\php{1}}+ \phm{1}\php{2}+\phm{1}\phm{2} + \comtr{\php{1}}{\phm{2}}
\end{align*}
The blue term was not normal ordered and hence in the last line, we made that normal ordered by introducing the commutator. The commutator gives us $ \comtr{\php{1}}{\phm{2}} = D(x-y)\equiv D\tund{12}$ where $D(x-y)$ is defined as in sec \ref{sec:propag}. \\[0.2cm]
As a shorthand, we denote the normal-ordering by $\SN\{\pho, \phii\} \equiv\  :\pho\phii:$, hence for $x_1^0>x_2^0$ 
$$\ST\{\phi_1, \phi_2\} =\ :\pho\phii: + D\tund{12}$$
If we calculate for the other case, $x_1^0<x_2^0$ then $1$ and $2$ are simply exchanged,
$$\ST\{\phi_1, \phi_2\} = \ :\pho\phii: + D\tund{21}$$
Thus in general we can write the time-ordered product in the following form 
\begin{align*}
    \ST\{\phi_1, \phi_2\} &= \ \Theta(x_2^0-x_1^0)[:\pho\phii: + D\tund{21}]+\Theta(x_1^0-x_2^0)[:\pho\phii: + D\tund{12}]\\ &=\ :\pho\phii:+ \Theta(x_2^0-x_1^0)D\tund{21} + \Theta(x_1^0-x_2^0) D\tund{21}\\ &= \ :\pho\phii: + \fp\tund{12}
\end{align*}
We should have been more careful with the above expression. The LHS is an operator, however the Feynman propagator $\fp\tund{ij}$ is just a complex number, hence we should have technically written $\fp\tund{12} \iden$. We define a \textit{contraction } as 
$$\wick[offset=1.1em]{\c\pho \c\phii} :=\fp\tund{12} \iden$$
Then the time-ordered product of two-fields can be written as 
$${ \ST\{\phi_1, \phi_2\} = \ :\pho\phii: + \wick[offset=1.1em]{\c\pho \c\phii}}$$
\subsection{The main theorem}
\begin{theorem}[Wick's Theorem]
    The time-ordered pairs of fields is given by 
    \[\ST\{\pho, \phii \ldots \phi_n\} = \ \sum\limits_{k=0}^{\lfloor \sfrac{n}{2}\rfloor} \sum_{\substack{\text{all } m  \\ \text{pairings}}} : \underbrace{\pho \phii \ldots \phi_n}_{\text{m contractions}}: \]
\end{theorem}
What the theorem says is that the time-ordered product of $n$ fields is the equal to the sum of operators formed by all possible contractions between the fields.\\[0.2cm] We now try to prove the theorem but before that let us see an example for $n=4$. Note that any contraction will remove $2$ fields and hence the maximum number of contractions possible is $\lfloor \sfrac{n}{2} \rfloor$. If $n$ is odd, then one field is always uncontracted. \\[0.2cm]
Applying this to four fields, we get 
\begin{align*}
    \ST\{\pho, \phii, \phiii, \phiv\} &= \ :\pho \phii \phiii \phiv: + \wick[offset=1.1em]{\c\pho \c\phii \phiii \phiv}+ \wick[offset=1.1em]{\c\pho \phii \c\phiii \phiv}+ \wick[offset=1.1em]{\c\pho \phii \phiii \c\phiv}+ \wick[offset=1.1em]{\pho \c\phii \c\phiii \phiv}\\
      &\qquad\qquad\quad\wick[offset=1.1em]{\pho \c\phii \phiii \c\phiv}+ \wick[offset=1.1em]{\pho \phii \c\phiii \c\phiv}+ \mathcolor{blue}{\wick[offset=1.1em]{\c1\pho \c1\phii \c2\phiii \c2\phiv}}+ \mathcolor{blue}{\wick[offset=1.1em]{\c1\pho \c2\phii \c1\phiii \c2\phiv}}+\mathcolor{blue}{\wick[offset=1.1em]{\c1\pho \c2\phii \c2\phiii \c1\phiv}}
\end{align*} 
where the contraction between two fields not adjacent to each other, like say $\wick[offset=1.1em]{\c\pho \phii \c\phiii \phiv}$, means that the Feynman propagator is between those two fields and the other fields are normal-ordered, that is,
$$(\fp\tund{13})(: \phii \phiv:)$$
\textit{Proof.} We have already proved it for $n=1$ and $n=2$. Let fields $\phi_1, \ldots, \phi_n$ be given and WLOG we can relabel the fields such that these become time-ordered, that is, $x_1^0\geq x_2^0\ldots \geq x_n^0$ and we claim that Wick's theorem is true for $(n-1)$ fields, $\phi_2, \phi_3 \ldots \phi_n$, that is 
 \[\ST\{\phii \ldots \phi_n\} = \ \sum\limits_{k=0}^{\lfloor \sfrac{(n-1)}{2}\rfloor} \sum_{\substack{\text{all } m  \\ \text{pairings}}} : \underbrace{\pho \phii \ldots \phi_n}_{\text{m contractions}}: \ \equiv \SW(\phii\ldots\phi_n)\]
 We have to now show that it is true for $n$ fields. Multiply both sides of the above equation by $\pho$. Since $x_1^0$ is greater than all other terms, the LHS becomes $\ST\{\pho\phii \ldots \phi_n\}$. Now the RHS becomes 
 \begin{align*}
    \pho \SW(\phii\ldots\phi_n) = (\php{1} + \phm{1}) \SW(\phii\ldots\phi_n)
 \end{align*}
 The second term is not problematic, since all the terms in $\SW$ are already normal ordered, so $\phm{1}$ can safely move in to the left, without disturbing the normal-ordering. For $\php{1}$ we need to send it to the extreme right and thus, we have to invoke the commutator. 
 $$ \pho \SW(\phii\ldots\phi_n) = \phm{1}\SW(\phii\ldots\phi_n) +\SW(\phii\ldots\phi_n)\php{1} + \comtr{\php{1}}{\SW(\phii\ldots\phi_n) } $$
%  The first two terms are normal-ordered, as $\SW$ contains all normal-ordered terms and $\phi^{\pm}$ are correctly placed to satisfy normal ordering. And the fields inside normal ordering can be arbitrarily placed since the operator ultimately orders them. Thus, 
%  \begin{align*}
%     \phm{1}\SW(\phii\ldots\phi_n) +\SW(\phii\ldots\phi_n)\php{1} &=  \SW(\phm{1}\phii\ldots\phi_n) +\SW(\phii\ldots\phi_n\php{1})\\ &=\SW(\phm{1}\phii\ldots\phi_n) +\SW(\php{1}\phii\ldots\phi_n)\\  &=\SW(\pho\phii\ldots\phi_n)
%  \end{align*}
\textcolor{red}{COMPLETE PROOF!}\\[0.2cm]
Note that when we take the vacuum expectation of the time-ordered product, all the terms with a dangling normal ordering is killed, since the creation and annihilation operators act on the vacuum from the right direction so as to kill it. Only those term survive where all the fields have been contracted. For $n=4$ only the blue terms survive which can be diagrammatically represented as \\[0.15cm]
