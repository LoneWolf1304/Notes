The states that we had defined earlier, $\ket{\vb{p}_1, \vb{p}_2, \ldots}$ are \textit{improper}, in the sense that they cannot be normalised. The obvious choice, $\braket{\vb{p}|\vb{p'}} = (2\pi)^3 \delt{3}{\vb{p}-\vb{p}'}$ is not physical due to the presence of the Dirac-delta. We can form physical states by `smearing out' these deltas, by defining:
$$\ket{\psi} = \int \meas{\vb{p}}\psi(\vb{p})\ket{\vb{p}} = \int \meas{\vb{p}}\psi(\vb{p})\crep\ket{\vac}$$ where $\psi(\vb{p})$ is an $\mathbb{L}^2$ function. However, this smearing process is not apriori Lorentz invariant. Thus, we can force the process to follow Lorentz invariance since the inception only, so that we do not run into trouble later.

\subsection{Invariant Inner Product}
For simplicity, consider a Lorentz boost along the $x$ direction. Then, 
$${p'}^1 = \gamma(p^1+\beta E)\qquad\qquad E' = \gamma(E+\beta p^1)$$
where $\gamma = \sfrac{1}{\sqrt{1-\qty(\sfrac{v}{c})^2}}$ and $\beta = \sfrac{v}{c}$ are defined as usual. Now, note that $p^\mu p_\mu = m^2 \implies E^2 = (p^0)^2 +(p^1)^2+(p^2)^2+m^2 \implies 0<E= \sqrt{(p^0)^2 +(p^1)^2+(p^2)^2+m^2}$ under the Minkowski metric. As the transformation is only along $x$ direction, the momentum in $x$ and $y$ do not change. Thus, we have:
$$\pdv{E}{p^j} = \frac{1}{2E}\times (2 p^j) \implies \pdv{E}{p^1} = \frac{p^1}{E}$$
Now, note the transformation of the Dirac-delta:
\begin{align*}
   \int \dd^3 \vb{y} \ \delt{3}{\vb{x}-\vb{y}} =  \int \dd^3 \vb{y}' \ \delt{3}{\vb{x}'-\vb{y}'} = \int \Big|\pdv{\vb{y}'}{\vb{y}}\Big| \dd^3 \vb{y} \ \delt{3}{\vb{x}'-\vb{y}'}
\end{align*}
Comparing, we see that the Dirac-delta transforms as $\delt{3}{\vb{x}-\vb{y}} = \Big|\pdv{\vb{y}'}{\vb{y}}\Big| \delt{3}{\vb{x}'-\vb{y}'}$ where $\Big|\pdv{\vb{y}'}{\vb{y}}\Big|$ is the determinant of the Jacobian matrix $J$ of the transformation. Hence, for the Lorentz transformation, we have:
\begin{align*}
   \delt{3}{\vb{p}-\vb{k}} &=  \delta(p^1-k^1) \delta(p^2-k^2) \delta(p^3-k^3)\\
   &= \mathfrak{J} \ \delta(p'^1-k'^1) \delta(p'^2-k'^2) \delta(p'^3-k'^3)
\end{align*}
Now, let us calculate the Jacobian matrix, whose elements will be given by $J^{ij} = \pdv{p'^i}{p^j}$ (note that since we are concerned only with 3-momentum delta function, only spatial indices will appear). Note that $\pdv{p'^2}{p^j} = \delta_{2j}$ and $\pdv{p'^3}{p^j} = \delta_{3j}$. Only for $j=1$, we have:
$$\pdv{p'^1}{p^j} = \gamma \delta_{1j} + \gamma\beta \pdv{E}{p^j}$$ and from the dispersion relation, we have $\pdv{E}{p^j} = \frac{p^j}{E}$. The matrix is then:
$$J \equiv \mqty(\gamma \qty(1+\beta \frac{p^1}{E}) & \gamma\beta \frac{p^2}{E} & \gamma\beta \frac{p^3}{E}\\ 0 & 1 & 0 \\ 0 & 0 & 1)\implies \mathfrak{J} =  \det J  = \gamma \qty(1+\beta \frac{p^1}{E}) = \frac{\gamma}{E} \qty(E+\beta p^1) = \frac{E'}{E}$$
Thus, we obtain the transformation of the delta function as:
$$   \delt{3}{\vb{p}-\vb{k}}= \frac{E'}{E}   \delt{3}{\vb{p}'-\vb{k}'}\implies E \delt{3}{\vb{p}-\vb{k}} \text{ is invariant under L.T} $$
Then, we can now define the Lorentz-invariant inner product such that:
$$\braket{\vb{p}|\vb{k}} =(2E_{\vb{p}}) (2\pi)^3 \delt{3}{\vb{p}-\vb{k}}\equiv (2\omp) (2\pi)^3 \delt{3}{\vb{p}-\vb{k}}$$
In line with this, we can therefore define a single-particle state as:
$$\ket{\vb{p}} = \sqrt{2\omp} \crep \vac$$
Technically, we should have made some distinct notation to differentiate between the states with and without proper normalisation, however, henceforth we will always use normalised states, so confusion might not be there. 
\subsection{Invariant Measure}
Define the \textit{projector} onto the single-particle state,
$$\mathds{1} := \int \meas{\vb{p}} \ket{\vb{p}}\bra{\vb{p}}$$
Here we have used the states with proper normalisation, obeying Lorentz invariance. The LHS is Lorentz invariant, since the operator essentially checks whether we have single particle or not, which is a frame independent fact. Thus, the only thing to change is the \textit{integral measure}!\\[0.2cm]
Consider the following integral,
$$\int \dd^4 p \ \delta((p^0)^2 -\tvec{p}^2- m^2) \Theta(p^0)$$
Note that, $\dd^4p$ is Lorentz invariant. Also, from the dispersion relation, we have:
$$p^\mu p_\mu = (p^0)^2 - \tvec{p}^2 = m^2$$
The dispersion relation is also Lorentz invariant, since it contains scalars $p^\mu p_\mu$ and $m^2$. Solving for $p^0$, we have $p^0 = \pm\sqrt{\tvec{p}^2 + m^2}$. Now, the choice of which branch to choose (poisitive or negative) is also Lorentz invariant, since here we are considering only \textit{orthochronous transformations}, which does not change the time component of the momentum. Thus, overall the integral is Lorentz-invariant.
\begin{align*}
   \int \dd^4 p \ \delta((p^0)^2 -\tvec{p}^2- m^2) \Theta(p^0)&=  \int \dd^4 p \ \delta((p^0)^2 -E_{\tvec{p}}^2)\Theta(p^0)\\
   &=\int d^3\vb{p} \int\limits_{-\infty}^\infty\dd p^0 \ \delta((p^0)^2 -E_{\tvec{p}}^2)\Theta(p^0) \\
   &=\int d^3\vb{p} \int\limits_{-\infty}^\infty \dd p^0 \ \frac{1}{2E_{\vb{p}}}\qty[\delta(p^0 +E_{\tvec{p}}) + \delta(p^0 -E_{\tvec{p}})]\Theta(p^0)\\
   &=\int\frac{ \dd^3\vb{p}}{2E_{\vb{p}}}
\end{align*}
Hence, whatever measure we were taking earlier, that is, $\meas{\vb{p}}$ was not Lorentz-invariant, however, as seen above,  $$\frac{ \dd^3\vb{p}}{(2\pi)^3}\frac{1}{2E_{\vb{p}}}\ \text{is manifestly Lorentz invariant}$$
Nice! So, henceforth we will always try to write the integrals in manifestly Lorentz invariant form, for example, the field expression becomes:
$$\hat{\phi}(x) = \int \meas{\vb{p}}\frac{1}{2\omp}\qty(\sqrt{2\omp} \annp e^{i \vb{p}\cdot \vb{x}} + \sqrt{2\omp}\crep e^{-i \vb{p}\cdot \vb{x}})$$
We could technically absorb the $\sqrt{2\omp}$ in the definition of the creation and annihilation operators which would make the new field expressions similar to the old ones, but it is not really needed!\\[0.2cm]
Finally, we can rewrite the identity operator on one-particle states as,
$$\mathds{1} := \int \meas{\vb{p}}\frac{1}{2\omp} \ket{\vb{p}}\bra{\vb{p}}$$
\subsection{Position states?}
Consider the field operator acting on the vacuum. Since annihilation operators kill the vacuum, we only have:
$$\hat{\phi}(x)\vac = \int \meas{\vb{p}}\frac{1}{2\omp} e^{-i \vb{p}\cdot \vb{x}}\ket{p}$$
Apart from the factor $\frac{1}{2\omp}$, this looks more or less like some position state since it is linear superposition of all well-defined momentum states. Also, note that:
\begin{align*}
   \bra{\Omega}\hat{\phi}(\vb{x})\ket{\vb{p}'} &= \bra{\Omega} \int \meas{\vb{p}} \frac{1}{2\omp} \qty(\sqrt{2\omp}\annp e^{i \vb{p}\cdot \vb{x}} + \sqrt{2\omp}\crep e^{-i \vb{p}\cdot \vb{x}} ) \sqrt{2\omp} \crepd \vac \\
   &=  \int \meas{\vb{p}} \qty( e^{i \vb{p}\cdot \vb{x}} )  \bra{\Omega} \annp\crepd \vac\\
   &=\int \meas{\vb{p}} \qty( e^{i \vb{p}\cdot \vb{x}} )  \bra{\Omega} (2\pi)^3\delt{3}{\vb{p}-\vb{p}'} + \crepd \annp \vac\\
   &=e^{i \vb{p}'\cdot \vb{x}}
\end{align*}
We can interpret this as the position-space representation of the single-particle state $\ket{\vb{p}}$, exactly as in non-relativistic quantum mechanics. Thus, we have:
$$\bra{\Omega}\hat{\phi}(\vb{x})\ket{\vb{p}} = \braket{x|p} = e^{i \vb{p}\cdot \vb{x}}$$
