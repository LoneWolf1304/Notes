\section*{Lecture 03: From Classical to Quantum}
\addcontentsline{toc}{section}{Lecture 03: From Classical to Quantum }
Inspecting the transition from a classical to quantum description is necessary for understanding QFT, which is just a \textit{sophisticated mechanics}. \\[0.2cm]
We know that the position $\vb{q}\equiv \{q_1,\ldots, q_n\}$ and momentum $\vb{p}\equiv \{p_1,\ldots,p_n\}$ uniquely define the state of a \textit{classical} particle. $$(\vb{q},\vb{p})\in \Pi \ \text{($2n$ dimensional phase space) }\qquad q_i,p_i\in \re$$
The Hamiltonian $H(\vb{q}, \vb{p})$ is just a way of performing time evolution on the system. Using the Hamiltonian, we can `fibrate' the phase space, that is, starting from one point, we can go to some other point. Also, note that, changing the parameters in the Hamiltonian (eg. $\omega$ in SHO Hamiltonian), we change the fibration patterns(eg. \textit{Lissajou's} figures).

In the quantum world, the phase space changes to the Hilbert space $\SH$ while a point in the phase space $(q,p)$ changes to a vector $\ket{\psi}$ in the Hilbert space.\\[0.2cm]
Also, these real variables become Hermitian (self-adjoint) operators \footnote{A self-adjoint operator $\SO$ is such that $\SO = \SO^\dagger$ in all respect, that is, $\SO$ and $\SO^\dagger$ have the same domain and action. In general, $\mathbb{D}(\SO)\subseteq \mathbb{D}(\SO^\dagger)$ where $\mathbb{D}(\cdot)$ represents the domain of some operator. If the domains are not equal but action is same on a restricted domain (mainly occurs in infinite-dimensional spaces), then those operators are not self-adjoint but called \textit{symmetric/Hermitian} (in some places Hermiticity also requires a symmetric operator to be bounded ). }and the classical Poisson bracket now transforms to the commutator.
\begin{align*}
    \text{CM:}&\qquad \{q,p\}=1\\
     \text{QM:}&\qquad [\hat{q},\hat{p}]=i
\end{align*} 
\subsection{Time Evolution}
% \addcontentsline{toc}{subsection}{Time Evolution}
From classical Hamilton's equations of motion, we have:
\begin{alignat*}{3}
    \dot{q}_i &= \{q_i,H\} &&= \pdv{H}{p_i}  \\
    \dot{p}_i &= \{p_i,H\} &&= -\pdv{H}{q_i}
\end{alignat*}
If $\vb{z} = \mqty(\vb{p}\\\vb{q})$ is a $2n$ dimensional vector, then $\dot{\vb{z}} = \{\vb{z},H\}$. Now, moving to quantum mechanics, we know the celebrated Schr\"odinger equation, which specifies the time evolution of a state vector $\ket{\psi(t)}\in \SH$:
$$i \pdv{\ket{\psi(t)}}{t} = H\ket{\psi(t)}$$
Thus, in both classical and quantum case, the time derivative of a quantity is equal to some action of the Hamiltonian on that quantity (classical \rightarrow \ Poisson bracket, quantum \rightarrow \ Multiplication with Hamiltonian)\footnote{A better analogy would be to use density matrices which gives the von Neumann equation which uses commutator bracket}. \\[0.2cm]
The Hamiltonian in the position basis becomes: $$H = \frac{-\hbar^2}{2m}\grad^2 + V(\vb{x})$$
Thus, the Schr\"odinger equation now acts on the wavefunction $\psi(\vb{x},t) = \braket{\vb{x}|\psi}$:
$$i \pdv{\psi(\vb{x},t)}{t} = -\frac{1}{2m}\grad^2 \psi(\vb{x},t) + V(\vb{x})\psi(x,t)$$
And the energy and momentum operators become $E\rightarrow i \pdv{t}$ and $p\rightarrow -i \grad$.
\subsubsection{Free Particle}
% \addcontentsline{toc}{subsubsection}{Free Particle}
The dispersion relation for a non-relativistic free particle is:
$$E = \frac{\vb{p}^2}{2m}$$
The typical solution can be written as plane-waves, $e^{i(\vb{k}\cdot\vb{x}-\omega t)} = e^{i(\vb{p}\cdot\vb{x} - Et)} \equiv \exp(-ip^\mu x_\mu)$ where we have used the repeated summation notation and taken the metric $\eta_{\mu\nu} = (+,-,-,-)$.\\[0.2cm]
For a relativistic free particle, the dispersion relation becomes:
$$E^2 = m^2 + p^2$$
Instead of the wavefunction $\psi(\vb{x},t)$, we will use $\phi(\vb{x},t)$, since the resulting equation actually acts on a scalar-field and $\phi$ is common notation for a scalar-field. Substituting the energy and momentum operators here, we get:
\begin{alignat*}{3}
    &\qquad\qquad \qquad i^2 \pdv[2]{\phi(\vb{x},t)}{t} &&= (-i)^2 \grad^2\phi(\vb{x},t) + m^2\phi(\vb{x},t)\\
  \implies  &  \pdv[2]{\phi(\vb{x},t)}{t} - \grad^2\phi(\vb{x},t) &&= -m^2 \phi(\vb{x},t)\\
  \implies & \qty(\quad  \pdv[2]{t} -\grad^2 +m^2)\phi(\vb{x},t) &&= 0
\end{alignat*}
The above equation is called the \textit{Klein-Gordon equation}. In covariant notation, we can compactly write it as:
$$\qty(\partial_\mu \partial^\mu +m^2)\phi(x^\nu) = 0 $$
The KG equation is Lorentz invariant, that is, under a Lorentz transformation, $x^\mu \rightarrow x'^\nu$, $\phi'(x'^\nu) = \phi(x^\mu)$
\subsubsection{Continuity Equation}
% \addcontentsline{toc}{subsubsection}{Continuity Equation}
Taking the complex cojungate of the Schr\"odinger's equation and then after some algebraic manipulation, we obtain:
\begin{align*}
     \pdv{(\psi^*\psi)}{t} = \frac{i}{2m} \grad \cdot \qty[\psi^*(\grad\psi) - \psi (\grad \psi^*)]
\end{align*}
Here, we identify:
$$\rho := \psi^*\psi\qquad\qquad \vb{J} = \frac{-i}{2m}\qty[\psi^*(\grad\psi) - \psi (\grad \psi^*)]$$ which yields the well-known form of the \textit{continuity equation}:
$$\pdv{\rho}{t} + \grad\cdot\vb{J} = 0\qquad \longrightarrow \qquad\partial_\mu J^\mu = 0$$
where $J^\mu = (\rho, \vb{J})$ is the four-current.
Note that in this case, $\rho$ is a positive-definite quantity and can indeed have the interpretation of probability. Also, note that if $\psi$ somehow becomes real-valued, then $\vb{J}=0$ which implies that $\rho$ is constant in time (though it can change in space). \\[0.2cm]
Doing the same thing to Klein-Gordon equation yields:
$$\pdv{t}\qty(\phi^*\pdv{\phi}{t}-\phi\pdv{\phi^*}{t})-\grad\cdot\qty(\phi^*\grad{\phi}-\phi\grad{\phi^*})=0$$
From this equation, we can identify:
$$\rho :=  \qty(\phi^*\pdv{\phi}{t}-\phi\pdv{\phi^*}{t}) \qquad\qquad \vb{J} := - \qty(\phi^*\grad{\phi}-\phi\grad{\phi^*})$$
Thus here, the 4-current becomes $J^\mu = \qty(\phi^* \partial^\mu \phi - \phi \partial^\mu \phi^*)$
Note the apparent problems with this identification:
\begin{itemize}
    \item It is not apriori obvious that $\rho$ is positive-definite and hence has problem with probability interpretation.
    \item The equation is second-order in time and hence $\rho$ seems to have a term evolving forward and one term evolving backward in time. 
    \item The dispersion relation does not have a single solution; the solutions are $\pm E$
\end{itemize}
The thing is, KG equation treats time and space on equal footing (unlike Schr\"odinger equation where time was in first order and space was in second order). Hence we have to consider all possibilities of moving back and forth in both space and time.
