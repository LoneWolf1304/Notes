\subsection{Order Parameter Flows for $m^4$}
Consider the previous case of $\SL$ with $m^3$ term. We can change this to a one-parameter problem by the following transformation. 
\textcolor{red}{do this}!\\[0.2cm]
From this, we obtain the following transformed function, 
\begin{equation}
    \phi(u) = \frac{1}{2}ru^2 - \frac{1}{3}u^3 + \frac{1}{4}u^4
\end{equation}
which depends only on the parameter $r$. The fixed point for $\phi(u)$ are found from solving $\phi'(u) = 0$,
$$ru - u^2 + u^3 = 0 \implies u=0 \quad \ \ u_\pm= \frac{1}{2}\pm \sqrt{\frac{1}{4}-r}$$
From the second derivative, we have $\phi''(u) = r - 2u +3u^2$. For $r>\frac{1}{4}$ we only have one fixed point, $u=0$ and $\phi''(u)=r>0$, hence $u=0$ is a \textit{stable fixed point}. Now, for $0<r<\frac{1}{4}$ we have three extremas for $\phi(u)$. \\[0.2cm]
For this case, $0<u_-<u_+$ and hence, $0$ and $u_+$  are the minimas while $u_-$ is the maxima (from the form of the potential). We need to check which of the minima is lower, for which we check $\phi(u) = \phi(0) = 0 $.\\[0.2cm] Multiplying this by $12$ and ignoring the $u=0$ roots, we have $6r - 4u + 3u^2 =0$. From minimisation condition, we further have $r - u + u^2 =0$. Solving this simultaneously yields $u = 3r $ and substituting this in any one of the equation gives us $r=\frac{2}{9}$ and $u=\frac{2}{3}$. Hence, for $r>\frac{2}{9}$, $u=0$ is the global minima while $u=\frac{2}{3}$ is the local minima, which changes for $r<\frac{2}{9}$.
