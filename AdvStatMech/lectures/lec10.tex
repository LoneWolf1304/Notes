\section*{Lecture 10: Some more on Ising Model}
\addcontentsline{toc}{section}{Lecture 10: Some more on Ising Model}
In the previous section, we noted some properties based on the symmetry of the Ising model. Let us now continue our discussion on the mean field solution, focussing on critical exponents, that we previously saw in the phase transition in fluids. 
\subsection{Critical Exponents}
Critical exponents are defined as the limiting \textit{power-law} behaviour of some thermodynamic quantities near the critical point. 
$$f(t)\sim t^\lambda \quad \implies \quad \lambda = \lim\limits_{t\to 0}\frac{\ln f(t)}{\ln t}$$
The variable $t$ is often taken to be the reduced temperature $t:=\frac{\pm(T-T_c)}{T_c}$ depending on whether we want to approach from below or above $T_c$. The reduced temperature kinda is a measure of the distance from critical point. It is taken dimensionless so that different models can be compared.\\[0.2cm] The critical exponents for $T_c^+$ and $T_c^-$ are found to be always equal, if they exist (Like for magnetisation, $m=0$ for $T>T_c$ so no exponent can be obtained in that case and hence, magnetisation is approached only from below $T_c$).\\[0.2cm]
From Eq. \eqref{transcendeq}, the mean field magnetisation was written as $\avg{\sigma}= \tanh(\beta h + \beta J \gamma \avg{s})$. Let us denote $m=\avg{\sigma}$ and $\tau = \frac{T_c}{T} = \beta J\gamma$. In terms of the reduced temperature $t = \frac{T_c-T}{T_c}$, we have $\tau = \frac{1}{1-t}$. Using $\tanh(x)\simeq x - \frac{x^3}{3}$ for $x\ll 1$, we get
\begin{align*}
    m = \tanh(\tau m) = \tanh(\frac{m}{1-t}) = \frac{m}{(1-t)} - \frac{m^3}{3(1-t)^3} + \ldots
\end{align*}
Solving this, we get $m=0$ or $m^2= (3t)(1-t)^2$. Note that for $T>T_c$, $t<0$ while $(1-t)^2>0 \ \forall t$. Hence, $m^2$ comes out to be negative, which is not possible. Thus for $T>T_c$ we only have one solution $m=0$. The non-zero magnetisation is thus interesting for us and let us check what is the scaling of this,
\begin{align*}
   m^2 = (3t)(1-t)^2 = 3t + \SO(t^2) \implies m\sim \pm (3t)^{1/2}
\end{align*}
Thus we obtain the first critical exponent from the mean-field analysis,
$${m\sim \qty(\frac{T_c-T}{T_c})^{\beta} \qquad\text{where, } \beta= \frac{1}{2}}$$
Now, let us check what happens when $h\neq 0$, along the critical isotherm $T=T_c \implies \tau=1$. For small $m$ and $ \qty(\sfrac{h}{\kb T_c}) \ll m$, the magnetisation equation becomes, 
\begin{align*}
    m = \tanh(\beta h + m) &\simeq (\beta h + m ) -\frac{1}{3}(\beta h + m )^3 + \ldots \\
    &=(\beta h + m ) -\frac{m^3}{3}\qty(\frac{3\beta h}{m} + 1 ) + \ldots
\end{align*}
From this we obtain a scaling between the field and magnetisation,
$$\beta h [1-m^2] = \frac{m^3}{3} \implies h = \frac{m^3}{3\beta(1-m^2)} = \frac{m^3}{3\beta}+\ldots\implies h \sim m^3$$
We obtained the second critical exponent from the mean-field analysis,
$${m\sim h^{1/\delta} \qquad\text{where, } \delta= 3}$$
We will now deal with the third exponent, but we have to be more careful here, since this will have scaling both above and below $T_c$. For this, again consider the transcendental equation $m = \tanh(\beta h + \tau m)$ which, after expansion around small $m$ and $h\ll m \kb T$, can be written as, 
$$h=\frac{m(1-\tau) +\frac{\tau^3 m^3}{3}}{\beta (1-\tau^2 m^2)}$$
Differentiating and retaining terms only upto $\SO(m^2)$, 
$$\qty(\pdv{h}{m})_T = \frac{ m^2 \tau ^2 +(1-\tau)}{ \beta  \left(m^2 \tau ^2-1\right)^2}$$
The denominator cannot provide any more $m^2$ term and hence upto $\SO(m^2)$, the derivative is given by, 
$$\qty(\pdv{h}{m})_T =  \frac{1}{\beta}\qty[\frac{m^2}{(1-t)^2} - \frac{t}{(1-t)}]$$
For $T>T_c$, $m=0$ and for $T<T_c$, $m^2 = 3t(1-t)^2$ as found before. Substituting this above, we get 
\begin{align*}
    \chi_+ &= \qty(\pdv{m}{h})_{T_c^+} = \frac{\beta (t-1)}{t} = \frac{1}{\kb T}\qty[1 - \frac{T_c}{T_c-T}] = \frac{1}{\kb (T -T_c)} \\
    \chi_- &= \qty(\pdv{m}{h})_{T_c^-} = \frac{\beta (1-t)}{t(2-3t)}\simeq \frac{\beta(1-t)}{2t} = \frac{1}{2\kb T }\qty[\frac{T_c}{T_c-T}-1] = \frac{1}{2\kb (T_c-T)}
\end{align*}
We obtained the scaling of the susceptibility, 
\begin{align*}
    \chi_+ &\sim (T-T_c)^{-\gamma'}\quad \text{where, }\gamma'=1\\
    \chi_- &\sim (T_c-T)^{-\gamma\ }\quad \text{where, }\gamma\ =1
\end{align*}
For $T\gg T_c$ then $\chi_+ \sim \frac{1}{T}$, in accordance with Curie's law. We see that $\gamma=\gamma'$ and hence, approach from both side of the critical point is the same. Also, $\frac{\chi_+}{\chi_-}=2 $ which is called the \textit{amplitude ratio}.

\end{figure}
\noindent
Fig. \ref{critexp} (a) shows the Ising model phase diagram. For low temperatures $T<T_c$, the system undergoes a discontinuous phase transition in which $m$ changes abruptly as it crosses from $h<0$ to $h>0$, denoting a first-order transition. Shown in red is the \textit{coexistence curve}, which ends at $T_c$. Beyond $T_c$, $m$ changes continuously across the $h<0$ to $h>0$ transition. \\[0.2cm]

\subsection{Bragg-Williams Approximation}
This is kind of an alternate mean-field description of the Ising model. Consider the Ising lattice containing $N$ spins, with say, $N\tund{+}$ up spins and $N_-$ down spins. Then the average magnetisation is given by,
\begin{align*}
    m = \frac{N\tund{+} - N_-}{N\tund{+}+N_-} = \frac{2N\tund{+}-N}{N} \implies \frac{N\tund{+}}{N} = \frac{1}{2}(m+1)
\end{align*}
The entropy of the system is defined as the number of ways by which a configuration with magnetisation $m$ can be produced. Hence, out of $N$ spins, we choose $N\tund{+}$ spins and the rest are set to $N_-$, which gives us,
\begin{align*}
   \Omega(N\tund{+}, N_-) = \frac{N!}{N\tund{+}! N_-!}  =\frac{N!}{\qty(\frac{N(1+m)}{2})!\qty(\frac{N(1-m)}{2})! } \qquad S = \kb \ln \Omega(N\tund{+}, N_-) 
\end{align*} 
Using Sterling's approximation, $\ln N! \approx N\ln N - N$ we obtain,
\begin{align*}
    \ln \Omega &\approx (N \ln N - N) - \frac{N(1+m)}{2}\ln \qty(\frac{N(1+m)}{2}) -\frac{N(1-m)}{2}\ln \qty(\frac{N(1-m)}{2})+N\\
    &=N\qty[\ln N  - \frac{(1+m)}{2}\ln \qty(\frac{N(1+m)}{2}) -\frac{(1-m)}{2}\ln \qty(\frac{N(1-m)}{2})]\\
    &=N\qty[\ln N  - \frac{(1+m)}{2}\ln \qty(1+m) -\frac{(1-m)}{2}\ln \qty(1-m) - \ln N - \ln 2]\\
    &=N\qty[\ln 2 - \frac{1+m}{2}\ln (1+m) - \frac{1-m}{2}\ln (1-m)]
\end{align*}
The mean-field energy of the Ising model is given by, 
\begin{align*}
    U = -\frac{J\gamma Nm^2}{2}-Nhm
\end{align*}
We can now calculate the free energy and minimise it to find the equation of state. 
\begin{align*}
    F(T,m,N) = U -TS = -\frac{J\gamma Nm^2}{2}-Nhm - N\kb T\qty[\ln 2 - \frac{1+m}{2}\ln (1+m) - \frac{1-m}{2}\ln (1-m)]
\end{align*}
which implies that,
\begin{align*}
    \pdv{F}{m} &= -JN\gamma m - Nh + \frac{N\kb T}{2}\qty[1 + \ln(1+m) -1 -\ln(1-m)] =-JN\gamma m - Nh + \frac{N\kb T}{2}\ln\frac{1+m}{1-m}=0\\
    &\implies  \frac{1+m}{1-m} = e^{2\beta(J\gamma m + h)} \implies m = \frac{e^{2\beta(J\gamma m + h)}-1}{e^{2\beta(J\gamma m + h)}+1} = \frac{e^{\beta(J\gamma m + h)} -e^{-\beta(J\gamma m + h)}}{e^{\beta(J\gamma m + h)} +e^{-\beta(J\gamma m + h)}} = \tanh(\beta(J\gamma m + h))
\end{align*}
Thus we obtained the same previous self-consistent equation $m = \tanh(\beta J\gamma m + \beta h)$ from this method. 
\subsection{Towards the Landau free energy}
Instead of writing the Ising partition function $\SZ(T,h,N)$ as a sum over all spin configurations, we can write it as a sum over all possible magnetisations $m$. We can write, 
\begin{align*}
    \SZ(T,h,N) = \sum\limits_m \sum\limits_{\{\sigma\}|m} e^{-\beta \SH(\{\sigma\}, N,h)} \approx \sum\limits_m \Omega(m,N) e^{-\beta \SH\tund{MF}(m,N,h)}
\end{align*}
where $\Omega(m,N)$ is just the \textit{degeneracy factor}, which tells us how many states are there with magnetisation $m$ and $\SH\tund{MF}$ is the mean-field Hamiltonian from Eq. \eqref{mfham}. The above sum can be approximated by an integral from $-1$ to $1$, taking magnetisation to be continuous:
\begin{align*}
     \SZ(T,h,N) &= \int\limits_{-1}^1 \dd m\ \Omega(m,N) e^{-\beta \SH\tund{MF}(m,N,h)}\\
     &=\int\limits_{-1}^1 \dd m\ e^{\ln \Omega(m,N)} e^{-\beta \SH\tund{MF}(m,N,h)}\\
     &=\int\limits_{-1}^1 \dd m\ e^{\ln \Omega(m,N) -\beta \SH\tund{MF}(m,N,h)}\\
     &=\int\limits_{-1}^1 \dd m\ e^{-\beta N\qty(\mathcolor{blue}{\frac{-J\gamma m^2}{2} - mh -\frac{\kb T}{N} \ln \Omega(m,N) } )}
\end{align*}
The blue term feels like some kind of thermodynamic potential but it depends both on $m$ and $h$. Hence this is some kind of pseudo-free energy called the \textit{Landau free energy} denoted by $\SL(m,h)$,
\begin{align*}
    \SL(m,h) = -\frac{\gamma J m^2}{2} - mh -\kb T \ln 2 + \frac{\kb T}{2}\qty[(1+m)\ln (1+m) + (1-m)\ln (1-m)]
\end{align*}
From saddle-point approximation, the integral will take the value at $m=m^*$, such that $N\SL(m^*,h)$ is minimum. Thus, 
\begin{align*}
    \pdv{\SL}{m}\Bigg|_{m^*} = -\gamma J m^* - h + \frac{\kb T}{2}\qty[1 +\ln(1+m^*) -1 - \ln(1-m^*)] =0 
\end{align*}
From this we obtain the same transcendental equation $\tanh(\beta h +\beta J \gamma m) = m$ as before. Let us see some insights from the plot of the Landau free energy.
\begin{figure}[H]
    \centering
    \includegraphics[scale=0.6]{codes/L_vs_m_h.pdf}
    \caption{$\SL$ vs. $m$ at different temperature regimes. The curves have been appropriately shifted so that $\SL(m=0)=0$}
    \label{landau}
\end{figure}
\noindent
Fig. \ref{landau} (a) shows the variation of $\SL(m)$ as $m$ is varied between $-1$ and $+1$. For the zero-field case, $\lfe$ is symmetric about $m=0$. For $T>T_c$ we have only one minima at $m=0$ and for $T<T_c$ we have two mimima at $\pm m\tund{0}$ while $m=0$ is a local maxima. The second derivative of the Landau free energy at $m=0$
\begin{align*}
    \pdv[2]{\lfe}{m}\Bigg|_{m=0} = -\gamma J + \frac{\kb T}{2}\qty[\frac{1}{1+m} + \frac{1}{1-m}]\Bigg|_{m=0} = -J\gamma +\kb T\implies  \pdv[2]{\lfe}{m}\Bigg|_{m=0, T=T_c} = 0  
\end{align*}
from our definition of $\kb T_c = J\gamma$. Thus, for all values of $h$, $m=0$ is an \textit{inflection point} for $T=T_c$ where the curvature disappears, as is evident in Fig. \ref{landau}. \\[0.2cm]
For $T<T_c$, $\lfe$ has two degenerate minima for $h=0$. However, when we take $h\neq 0$ then these minima becomes non-degenerate, one becomes the stable minima and one becomes the metastable one (depending on the sign of $h$). On increasing $h$, the magnetisation metastable minima keeps getting shallower and at some $h=h^*$ (called the \textit{spinodal field}), it disappears completely as shown in Fig. \ref{spinodal}. The condition for this is that $\pdv{\lfe}{m} = 0$ and  $\pdv[2]{\lfe}{m} = 0$, which gives us 
\begin{equation*}
    m - \tanh\qty(\beta h + \beta J \gamma m) =0\qquad 1-\beta J\gamma \sech^2\qty(\beta h + \beta J \gamma m) = 0
\end{equation*}
Using $\sech^2(\beta h + \beta J \gamma m) = 1- \tanh^2(\beta h + \beta J \gamma m) $ we obtain $m^* = \pm \sqrt{1 - \frac{1}{\beta J \gamma}}$. What happens is that, for $h>0$ the metastable minima is at $m<0$ and this is given by $m^* = -\sqrt{1 - \frac{1}{\beta J \gamma}}$ while for $h<0$, $m^* = +\sqrt{1 - \frac{1}{\beta J \gamma}}$ is the metastable magnetisation. From these \textit{spinodal magnetisation}, we obtain the spinodal fields by substituting this in the expression of $\beta h = \tanh^{-1}(m) - \beta J \gamma m $ according to whether $h<0$ or $h>0$.
\begin{equation*}
    \beta h^* = \frac{1}{2}\ln\qty[\frac{1+m^*}{1-m^*}] - \beta J \gamma m^*
\end{equation*}
\noindent
Hence to summarise, we have the following cases:
\begin{itemize}
    \item $h=0 \ \longrightarrow$ degenerate, equally likely minima at $\pm m\tund{0}$ for $T<T_c$.
    \item $h\neq 0, h<h^* \ \longrightarrow$ one stable and one metastable minima. 
    \item $h\neq 0, h>h^* \ \longrightarrow$ only one stable minima.
\end{itemize}

\subsection{Hysterisis}
On varying the magnetic field at some fixed temperature $T<T_c$, we obtain a hysterisis in the Ising model. Suppose we start with a high negative value of $h\gg -|h^*|$. In this case, only one \textit{global minima} is present (see Fig. \ref{hysterisis} (a)). As we decrease the field magnitude (take the field towards zero), then at $h=-|h^*|$, the metastable minima will appear, but the system will be sitting in the global minima. At $h=0$, the global and the metastable minima will become degenerate. On increasing $h$ further in the positive side, the previous global minima now become the metastable minima. 
\begin{figure}[H]
    \centering 
    \includegraphics[scale=0.6]{codes/hysterisis.pdf}
    \caption{\textbf{Hysterisis curve from mean-field theory}. (a) $\lfe(m)$ vs. $m$ in different field regimes. The global minima shifts on moving $h$ from negative to positive. (b) Magnetisation vs. $h$ curve, showing the hysterisis loop.}
    \label{hysterisis}
\end{figure}
\noindent
The system should technically be sitting in the global minima, however, since it was previously occupying the other minima (which has now become metastable), due to some kind of \textit{inertia}, it still stays in the metastable state, which happens until $h$ hits $+|h^*|$. After that, the metastable minima disappears and the system is forced to relocate to the global minima.\\[0.2cm]
As shown in Fig. \ref{hysterisis} (b), the black arrows traverse the path when we start from $h<0$ while the red arrows show the same when starting from $h>0$. We can see that the paths are not the same and the resulting $m(h)$ curve is not reversible in time. This is the characteristic case of \textit{hysterisis}!
